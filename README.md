## Исследуемые индустриальные кейсы

В рамках выполнения курсового проекта был проведен комплексный первичный технический анализ четырех различных типов наборов данных на языке Python:

### 1. Первичный анализ набора табличных данных
* **Кейс:** №58 «Прогнозирование стоимости медицинской страховки»
* **Индустриальный партнер:** ОГБУ «ЧРЦНИТ»
* **Решаемая задача:** Вещественная регрессия — автоматизация финансового скоринга и прогнозирование годовых расходов на медицинское страхование клиентов на основе их физических и демографических параметров.

### 2. Первичный анализ набора данных с временными рядами
* **Кейс:** №60 «Коррекция массового расхода кориолисового расходомера при газожидкостном потоке»
* **Индустриальный партнер:** НИЛ Технической самодиагностики ЮУрГУ / ПАО «Северсталь»
* **Решаемая задача:** Временная регрессия и фильтрация — выделение полезных трендов, анализ высокочастотных гидродинамических шумов и интеллектуальная коррекция показаний расходомеров в условиях завоздушивания трубы.

### 3. Первичный анализ набора данных с изображениями
* **Кейс:** №48 «Разработать модель, способную идентифицировать средства индивидуальной защиты (СИЗ)»
* **Индустриальный партнер:** ПАО «ЧКПЗ»
* **Решаемая задача:** Детекция объектов (Object Detection) — автоматический контроль соблюдения техники безопасности на прессовом производстве, поиск силуэтов рабочих и распознавание элементов экипировки (касок, жилетов) в условиях сложного промышленного фона.

### 4. Первичный анализ набора текстовых данных
* **Кейс:** №68 «Определение тематики обращения с помощью ИИ»
* **Индустриальный партнер:** ОГБУ «ЧРЦНИТ» / ПАО Сбербанк
* **Решаемая задача:** Обработка естественного языка (NLP) и информационный поиск — синтаксическая очистка, лемматизация, фильтрация стоп-слов, расчет статистических весов TF-IDF и реализация алгоритма семантического поиска текстовых обращений по косинусному сходству.
