# Medical Insurance Price Prediction Dataset

## Описание
Датасет содержит верифицированные демографические и физические параметры клиентов страховой компании. В рамках курсового проекта данные применяются для решения задачи вещественной регрессии — прогнозирования индивидуальной стоимости годового медицинского страхования на основе признаков пользователя.

## Характеристики
* **Тип данных:** Табличные (структурированные) данные
* **Формат файлов:** CSV
* **Объем выборки:** 1338 уникальных наблюдений (строк), 7 признаков (столбцов)
* **Разметка:** Целевой непрерывный признак `charges` (стоимость страховки в USD)

## Структура признаков
Каждая запись содержит:
* `age` — возраст застрахованного лица (числовой тип)
* `sex` — пол клиента (категориальный тип: male / female)
* `bmi` — индекс массы тела (числовой тип)
* `children` — количество детей / иждивенцев (числовой тип)
* `smoker` — статус курения (категориальный тип: yes / no)
* `region` — регион проживания в США (категориальный тип)
* `charges` — годовые медицинские расходы (целевая переменная)
