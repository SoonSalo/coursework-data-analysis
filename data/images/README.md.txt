# PPE (Personal Protective Equipment) Detection Dataset

## Описание
Набор данных содержит цветные цифровые изображения производственных сцен и строительных площадок с соответствующими файлами текстовых аннотаций в формате YOLO. В рамках курсового проекта данные применяются для решения задачи детекции объектов (Object Detection) — автоматического контроля наличия средств индивидуальной защиты (касок и жилетов) на сотрудниках прессового цеха ПАО «ЧКПЗ».

## Характеристики
* **Тип данных:** Графические файлы (изображения) и текстовые аннотации разметки
* **Формат файлов:** `.jpg` (изображения) и `.txt` (координаты рамок в формате YOLO)
* **Объем выборки:** 260 уникальных изображений и 260 файлов разметки (подмножество train)
* **Разрешение картинок:** 640×640 пикселей (цветовое пространство RGB, 3 канала)

## Структура аннотаций
Каждая строка в текстовом файле аннотации соответствует одному объекту и содержит 5 нормализованных чисел: `[class_id, x_center, y_center, width, height]`.
Целевые классы разметки:
* `0 (Hardhat)` — защитная каска на голове сотрудника
* `1 (Safety Vest)` — светоотражающий сигнальный жилет
* `2 (NO-Hardhat)` — голова сотрудника без каски (нарушение техники безопасности)
* `3 (NO-Safety Vest)` — торс человека без жилета (нарушение техники безопасности)
* `4 (Person)` — силуэт человека (рабочего) целиком
