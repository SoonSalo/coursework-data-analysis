# Russian Citizen Requests Baseline Dataset

## Описание
Набор данных представляет собой русскоязычный текстовый корпус, состоящий из входящих электронных обращений граждан и соответствующих ответов автоматизированных систем. В рамках курсового проекта данные применяются для решения задач многоклассовой классификации документов и тестирования алгоритмов семантического информационного поиска на основе метрики косинусного сходства векторов TF-IDF.

## Характеристики
* **Тип данных:** Текстовые данные (корпус на русском языке)
* **Формат файлов:** TXT (структурированный лог с префиксами диалогов)
* **Объем выборки:** 599 строк (около 300 пар вида «Вопрос—Ответ»)
* **Разметка:** Целевые текстовые категории `Вопросы клиентов` и `Ответы системы`

## Структура аннотаций
Каждая запись в исходном текстовом документе имеет префикс канала фиксации:
* `Q:` — сырой входящий текст вопроса или жалобы гражданина на русском языке
* `A:` — официальный регламентированный текст ответа автоматической справочной системы
